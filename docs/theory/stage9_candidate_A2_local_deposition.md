# Stage 9 Candidate A2 — local covariant deposition gate

## Purpose

Candidate A2 closes the source side of the advected-state route without using the Milky Way halo residual to choose an amplitude or spatial scale.

## Minimal local scalar source

The persistent scalar q_H obeys the A0 transport equation

u_H^mu nabla_mu q_H + q_H/tau = S_q.

A source proportional to T itself would violate the Stage-9 rule because a static/comoving matter distribution would continuously regenerate persistence. The lowest-order local scalar that automatically vanishes for a static/comoving source is instead the state-frame derivative

D_U T = u_H^mu nabla_mu T.

For nonrelativistic baryons, T approximately equals -rho_b c^2, so this reduces to a source proportional to D_U rho_b.

## Dimensionless closure

Because q_H is dimensionless, one dimensionally closed form is

S_q = kappa_q tau D_U(T/T_star),

where T_star is a universal stress/curvature scale and kappa_q a universal dimensionless coefficient.

The product kappa_q/T_star is not a Milky Way fit parameter. It must come from the parent action or an external calibration that is independent of Delta a(R), Portail17/Hunter24 halo solutions, orbit weights, or any galaxy-specific residual.

## Static-source guardrail

If D_U T=0, then S_q=0 exactly. Existing q_H then simply relaxes/advects according to A0 rather than being continuously regenerated by static matter.

## Remaining theory requirements

Before A2 can generate a Milky Way q_H field, the parent theory must independently derive:

1. why the trace derivative, rather than another same-order invariant, is the correct deposited quantity;
2. the universal scale T_star;
3. kappa_q;
4. sign conventions and GR recovery;
5. equivalence-principle consistency;
6. cosmological background behavior;
7. initial-state prescription;
8. all ingredients frozen before halo comparison.

Therefore A2 is a deposition gate and dimensional closure, not yet a force-generating result.
