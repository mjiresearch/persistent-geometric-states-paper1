A first-order state equation of the form

\[
D_U Q_H + \frac{Q_H}{\tau}=S_H,
\qquad
D_U=u_H^\mu\nabla_\mu,
\]

moves the state along a timelike state-frame congruence.  In the weak-field limit,

\[
D_U\simeq\partial_t+\mathbf v_H\cdot\nabla.
\]

The displacement scale is then set by the *physical state-frame flow history* integrated over the survival time, not by pretending that a new gravitational radiation mode propagates at km/s speeds.

This directly represents the moving-background / moving-wave-tank possibility: source-generated state can be left behind or advected relative to the present baryons while the ambient geometric-state frame itself has nontrivial motion.
