# Stage 9 Candidate L0 — minimal causal linear persistence response

Date: 2026-08-10

## Status

Candidate L0 is a deliberately minimal **linear weak-field closure** of the persistence requirements already stated in the manuscript. It is introduced before any comparison with Portail17+halo, Hunter24+halo, the Milky Way acceleration residual, or orbit-weight targets.

It is a candidate effective law, not a derivation from a completed covariant parent action. Its purpose is to turn the manuscript's causal/relaxational requirements into the weakest hyperbolic field equation that can be falsified without using a halo-shaped force kernel.

## State variable

Let \(\Psi_H(\mathbf x,t)\) be the scalar weak-field persistence potential in the local rest frame of the persistent geometric-state congruence. It has the same dimensions as the ordinary weak-field baryonic potential \(\Phi_b\).

The inherited acceleration at strictly linear order is

\[
\mathbf a_H = -\nabla \Psi_H.
\]

For Candidate L0 the nonlinear inherited/contemporary interaction is frozen to

\[
\mathbf a_{\rm int}=0,
\]

which is the manuscript's allowed strictly-linear limit. A later nonzero interaction law must be introduced as a separate predeclared theory extension and cannot be selected because it improves a Milky Way halo comparison.

## Transport equation

Define the derivative along the persistent-state frame by

\[
D_H \equiv \partial_t + \mathbf u_H\!\cdot\!\nabla.
\]

Candidate L0 is

\[
\boxed{
D_H^2\Psi_H
+\frac{2}{\tau}D_H\Psi_H
-c_H^2\nabla^2\Psi_H
+\frac{1}{\tau^2}\Psi_H
=
\frac{\kappa}{\tau}D_H\Phi_b
}
\]

with

\[
0<c_H\le c,\qquad \tau>0.
\]

The associated correlation/propagation scale is

\[
\ell_H=c_H\tau.
\]

The principal part is hyperbolic, so disturbances propagate at finite characteristic speed \(c_H\). For a spatially uniform free mode the homogeneous operator is

\[
(D_H+\tau^{-1})^2\Psi_H=0,
\]

so the state relaxes rather than accumulating without bound.

## Deposition law

The source is **not** \(\rho_b\), \(\Phi_b\), or a second Poisson source. It is the change of the ordinary baryonic potential measured in the persistence frame,

\[
S_H \equiv D_H\Phi_b.
\]

Therefore a baryonic configuration that is static and comoving with the persistent-state frame satisfies

\[
D_H\Phi_b=0
\]

and does not continuously generate a duplicate gravitational field.

Motion, assembly, migration, mergers, bar evolution, disk reorientation, and other source changes may generate nonzero deposition because they change \(\Phi_b\) along the state-frame congruence.

## Normalization

The first preregistered L0 hypothesis fixes

\[
\kappa=1.
\]

This is a **unit-deposition candidate**, not a fitted amplitude. It must be run and reported before any alternative universal coupling is considered. It may fail by being too weak, too strong, or having the wrong geometry; such failure is scientifically meaningful.

Candidate L0 does not use the Milky Way halo residual to set \(\kappa\), \(c_H\), \(\tau\), the source orientation, or any spatial kernel shape.

## Characteristic-speed treatment

The existing Stage 9 memory-time grid remains

\[
\tau=1,2,4,8,16\ {\rm Gyr}.
\]

The first L0 propagation-speed case is frozen to the relativistic upper-bound value

\[
c_H=c.
\]

This choice introduces no additional tunable subluminal scale and gives the theory its longest causal correlation length for each \(\tau\). If L0-c fails, later subluminal cases may be introduced only as explicitly separate sensitivity tests, not selected by scanning halo agreement.

## Important change to the provisional source pipeline

The earlier Stage 9 source scaffold applied an exponential weight \(\exp(-t/\tau)\) only to construct a provisional hereditary source cloud before an explicit field equation existed.

Candidate L0 has its own retarded Green function and relaxation. Therefore **the exponential weighting must not be applied before solving L0**. Doing both would double-count temporal relaxation.

For L0 the solver must consume the raw time-resolved baryonic history, apply the historical orientation operator \(R(t)\), construct \(\Phi_b(\mathbf x,t)\), evaluate \(D_H\Phi_b\), and then evolve the hyperbolic equation.

The existing \(\tau\) values are retained as the predeclared relaxation grid, but the temporal response is generated by L0 itself.

## Initial data and GR limit

Candidate L0 requires independent initial data

\[
\Psi_H(t_i,\mathbf x),\qquad D_H\Psi_H(t_i,\mathbf x).
\]

The canonical first test uses the minimal relaxed initial state

\[
\Psi_H(t_i,\mathbf x)=0,
\qquad
D_H\Psi_H(t_i,\mathbf x)=0
\]

at the beginning of the reconstructed history. This is a boundary assumption and must be reported as such.

When the persistence coupling is removed, \(\kappa\to0\), and the initial persistent state is zero, the unique solution is \(\Psi_H=0\). Thus

\[
\mathbf a_H\to0,
\qquad
\mathbf a_{\rm dyn}\to\mathbf a_b,
\]

providing continuous recovery of the ordinary baryonic weak-field solution.

## What L0 does not contain

Candidate L0 does not contain:

- a dark-matter density;
- an NFW or other halo radial profile;
- a second instantaneous Poisson equation for historical mass;
- galaxy-specific normalization;
- a fitted spatial softening length;
- a nonlinear interaction term;
- a preferred 90-degree Milky Way flip;
- or a parameter selected by maximizing agreement with Portail17/Hunter24.

## Predeclared falsification criteria

Candidate L0 should be regarded as unsuccessful for the Milky Way test if, with the source-history limitations explicitly propagated, it fails one or more of the following without post-hoc retuning:

1. it cannot generate a stable causal field over the reconstructed history;
2. it produces the wrong sign or gross radial scale for the required residual acceleration;
3. it improves one halo comparison only by degrading the other severely;
4. it produces orbit-weight agreement no better than the baryons-only control;
5. its apparent success exists only for an orientation or \(\tau\) chosen after examining halo targets;
6. it requires a fitted amplitude or spatial kernel to become viable.
