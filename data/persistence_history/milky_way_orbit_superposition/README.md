# Milky Way orbit-superposition outputs

This directory is reserved for generated Stage 8 products from the controlled mwsuperpos comparison.

Expected products include:

- `comparison_summary.csv` — four-way Portail/Hunter × full/baryons-only diagnostics;
- `persistence_replacement_target.npz` — radial full-minus-baryonic acceleration targets;
- per-run normalized weight products and reconstruction diagnostics;
- validation logs and checksums for the exact APOGEE/DistMass inputs used.

No placeholder numerical results should be interpreted as scientific output. Real-data products should be committed only after the source catalogs, code version, potential choice, and run configuration are recorded.
