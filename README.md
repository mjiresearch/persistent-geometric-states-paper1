# Persistent Geometric States — Paper I

Reproducibility materials for an **independent, in-progress empirical test** of the manuscript *Persistent Geometric States in General Relativity: A Hereditary Framework for Galactic Rotation Curves*.

## Researcher

**Michael Iuliano** — Independent Researcher  
**ORCID:** [0009-0004-9190-9865](https://orcid.org/0009-0004-9190-9865)

## Current scientific status

This repository is a working reproducibility archive, not a claim that the proposed framework has been empirically established.

The stationary analysis is being constructed under a predeclared calibration/blind-validation protocol. Observational inputs, sample membership, source reconstruction, numerical validation, and synthetic-recovery tests are being documented and frozen before the final persistence parameters are inferred or the blind sample is evaluated.

At the present stage, **no final empirical conclusion is reported here**.

## Purpose

Large observational tables, machine-readable audit products, validation outputs, and analysis code are maintained here rather than embedded directly in the manuscript appendices.

The manuscript appendices describe the methods, definitions, selection rules, validation tests, and principal results. Where appropriate, each appendix links to the corresponding version-controlled material in this repository.

## Data stewardship and third-party data

This repository distinguishes between:

- **public source data** — material that may be redistributed under the source provider's terms;
- **derived products** — transformations, audit tables, validation products, and scientific outputs generated by this project; and
- **restricted or non-public source data** — third-party material supplied privately or under terms that do not authorize redistribution.

Restricted or non-public third-party source files will **not** be posted in this public repository without explicit permission from the data provider. When such data are required for an analysis, the repository will instead record provenance, checksums where appropriate, processing code, permitted derived products, and instructions sufficient to document how the data enter the analysis.

Providing observational data to this project does **not** imply collaboration, endorsement of the theoretical framework, or endorsement of any conclusions. Data providers and source publications will be cited and acknowledged according to their requested terms.

See [`DATA_POLICY.md`](DATA_POLICY.md) for the repository's detailed data-handling policy.

## Stationary SPARC observational master

The audited observational master is:

`data/stationary/frozen/stationary_master_v1.csv`

Its construction and validation establish:

- provenance against authoritative SPARC source material;
- column definitions and physical units;
- galaxy and radial-point counts;
- duplicate handling;
- missing-value / NaN handling;
- preservation of the signed SPARC gas contribution;
- radial ordering within each galaxy;
- explicit selection and exclusion criteria; and
- reproducible checks against the authoritative observational data.

A frozen product is not silently overwritten. Subsequent substantive changes receive a new version identifier.

## Source-current reconstruction

The stationary persistence operator requires the baryonic source distribution rather than only the decomposed Newtonian rotation-curve contributions. In particular, the published SPARC `Vgas(R)` quantity is not treated as an H I surface-density profile.

The radial H I source-profile acquisition and validation stage is documented under:

`data/stationary/source_reconstruction/`

Any non-public H I profiles obtained from an external researcher will remain excluded from this public repository unless redistribution is explicitly authorized.

## Data-status terminology

- **raw** — source or source-derived material retained for provenance where redistribution is permitted;
- **processed** — intermediate/reconstructed products still subject to validation;
- **frozen** — audited version used for reported manuscript results;
- **validation** — machine-readable audit and comparison products.

## Reproducibility principle

Numerical values reported in Paper I must be traceable to a frozen input dataset, a versioned analysis procedure, and a reproducible output. Placeholder, pilot, exploratory, or illustrative values are not presented as final empirical results.

The calibration/blind split and source-reconstruction rules are established without reference to the final persistence residuals. Post-unblinding changes, if any, must be explicitly labeled exploratory and cannot replace the original frozen blind result.

## Appendices

The manuscript appendices remain readable scientific documents rather than repositories for thousands of machine-readable rows. Appendix sections therefore summarize methods and results and link to corresponding repository directories/files when the underlying tables, diagnostics, or code are too large for the manuscript.
